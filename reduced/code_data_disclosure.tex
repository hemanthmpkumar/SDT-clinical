\subsection*{3. Code and Software Availability Disclosure}

\subsubsection*{3.1 Source Code and Implementation}
The complete algorithmic implementation of the Spectral Diagnostic Trajectories (SDT) framework is provided under an open-source permissive license (\textbf{Apache License 2.0} / \textbf{MIT License}):
\begin{itemize}\setlength{\itemsep}{0.5pt}\setlength{\parskip}{0pt}
    \item \textbf{Public Code Repository:} \url{https://github.com/hemanthmpkumar/SDT-clinical}
    \item \textbf{Permanent Archive / Zenodo DOI:} \href{https://doi.org/10.5281/zenodo.12345678}{10.5281/zenodo.12345678} (assigned upon final publication)
    \item \textbf{Reproducibility Package Structure:}
    \begin{itemize}\setlength{\itemsep}{0.5pt}\setlength{\parskip}{0pt}
        \item \texttt{src/sdt/phase1\_hypergraph.py}: Multi-modal hypergraph construction and incidence matrices.
        \item \texttt{src/sdt/phase2\_fiedler.py}: Lanczos eigensolver for algebraic connectivity ($\lambda_2$) tracking and pivot detection.
        \item \texttt{src/sdt/phase3\_attenuation.py}: Chebyshev polynomial graph-signal attenuation with Cheeger bounds.
        \item \texttt{src/sdt/phase4\_prefetch.py}: Eigenspace-biased random walk and Sweller cognitive-load knapsack optimizer.
        \item \texttt{src/sdt/phase5\_evaluation.py}: 9-arm simulation benchmark and statistical evaluation pipeline.
        \item \texttt{src/sdt/sdt\_retriever.py}: Unified retriever interface with CDS Hooks and SMART-on-FHIR bindings.
        \item \texttt{src/analysis/queueing\_model.py}: Erlang C ($M/M/c$) emergency department queueing simulation.
    \end{itemize}
\end{itemize}
